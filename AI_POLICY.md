I started this project back in 2017 as a learning tool for the community. The intent was to give developers a chance to learn how to contribute to open source projects and to play with software development. I understand that recent advancements in AI have changed the ways in which we interact with code, and I want developers to be able to play with all tools. However, this needs to be done with the intent of learning. You are free to use AI while contributing to this project. I expect there to always be a "human in the loop" who understands and can explain any content that AI generates. So, please don't use AI to take away an opportunity from yourself or others by relying too heavily on AI-assisted development.

*Please respect the following policies:*

*Do not communicate through LLM-generated text.* We want you to use your own words when describing PRs, commits, issues, or any other communication around this project. Any LLM-generated text must be clearly marked and supplemented by text you wrote yourself.

*Thoroughly review and understand any AI-generated code before submitting.* This practice helps us maintain high code quality standards, facilitates meaningful review discussions with maintainers, and increases the likelihood that your submission will be accepted.

*Contribute at human speed, not AI speed.* AI can be used to do many things very fast, but our project moves at human speed. Please do not do things like posting large amounts of LLM text back-to-back or rapidly claiming and generating solutions to a large number of issues.

*Do not use AI to one-shot good first issues.* Issues labeled as "good first issue" are intended to help newcomers learn about the codebase, and there are only a limited number of them available. Please do not use AI to complete these issues without any input of your own.

*Contributions from autonomous AI agents are not accepted.* We may close PRs that we believe were prepared without human involvement.
